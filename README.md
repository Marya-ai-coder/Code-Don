# Генератор рекламного контента (Центр-инвест)

Веб-приложение на **Streamlit** для генерации рекламных материалов, постов, слоганов и баннеров банка «Центр-инвест».

## 🎯 Реализованный функционал (роль «Разработчик модуля ввода»)

1. **Конфигурация страницы и каркас формы**:
   - Настройка страницы (`st.set_page_config`) с заголовком и стилизацией.
   - Заголовок (`st.title`) и поясняющие подсказки (`st.caption`).
   - Изолированная форма ввода через контейнер `st.form("ad_input_form")`.

2. **Поля ввода и форматы рекламы**:
   - Поле `st.text_area` для описания рекламной кампании, продукта или условий акции.
   - Поле `st.selectbox` для выбора рекламного формата:
     - *Рекламный пост для соцсетей (VK / Telegram)*
     - *Продающий слоган и УТП*
     - *Текст для баннера / сторис*
     - *Акционное предложение (кэшбэк, скидки)*
   - Кнопка отправки формы `st.form_submit_button("🚀 Сгенерировать рекламу")`.

3. **Отображение результата и копирование**:
   - Вывод сгенерированного текста в блоке `st.code(..., language=None)` со встроенной кнопкой быстрого копирования в буфер обмена в один клик.

4. **Кнопка «Перегенерировать»**:
   - Кнопка `st.button("🔄 Перегенерировать")` размещена строго вне формы.
   - Реализована блокировка `disabled=not has_result` (неактивна, если нет сгенерированного ответа).
   - При нажатии повторно вызывает логику генерации для сохраненного запроса и обновляет интерфейс через `st.rerun()`.

5. **Надежность и точка интеграции с моделью**:
   - Валидация входных данных на пустоту (`.strip()`) с выводом предупреждения через `st.error`.
   - Перехват исключений через `try / except` с выводом ошибки в UI.
   - Сохранение состояния между перезапусками страницы через `st.session_state`.
   - Подготовлена точка интеграции для модели «Центр-инвест» (`CENTRINVEST_API_KEY`).
   - Встроен автономный демонстрационный генератор целевых рекламных текстов банка «Центр-инвест».

---

## 💻 Локальный запуск

1. Установите зависимости:
   ```bash
   pip install -r requirements.txt
   ```

2. Запустите Streamlit-приложение:
   ```bash
   streamlit run app.py
   ```

3. Откройте в браузере: `http://localhost:8501`.
