# ИИ-помощник для рекламных текстов

Desktop-приложение для создания рекламных материалов банка «Центр-инвест». Программа позволяет вводить параметры продукта, адаптировать текст под целевую аудиторию, выбирать площадку и тональность, получать варианты через ChatCI и проверять результат по базовым рекламным правилам.

## Возможности

- современное desktop-окно на PySide6;
- фон `fon.jpg` и полупрозрачные glass-панели;
- светлая голубая цветовая схема, скруглённые поля и вкладки;
- генерация трёх рекламных вариантов;
- подключение ChatCI через OpenAI-compatible API;
- шаблонный фолбэк, если ключ отсутствует или API недоступен;
- выбор площадки, аудитории и тональности;
- поле для своей аудитории;
- редактирование, копирование и перегенерация вариантов;
- проверка длины, CTA, запрещённых и спорных формулировок;
- работа без ключа в демонстрационном режиме.

## Структура проекта

```text
Code-Don/
├── app_qt.py                 # запуск новой desktop-версии
├── ui_qt.py                  # окно PySide6, UI/UX и стили
├── app.py                    # логика генерации, ChatCI и резервная Tkinter-версия
├── guides.py                 # аудитории, тональности, площадки и лимиты
├── validator.py              # проверка рекламных текстов
├── config.py                 # локальные настройки API (не публиковать)
├── config.example.py         # безопасный пример конфигурации
├── fon.jpg                   # фоновое изображение
├── requirements.txt          # зависимости Python
└── README.md                 # документация проекта
```

## Требования

- Python 3.10 или новее;
- PySide6, requests и Pillow;
- интернет для работы ChatCI.

## Установка

```powershell
cd C:\Users\<имя_пользователя>\Code-Don
python -m pip install -r requirements.txt
```

Если команда `python` не работает, используйте `py`.

## Настройка ChatCI

Создайте локальный файл конфигурации из шаблона:

```powershell
copy config.example.py config.py
```

Откройте `config.py` и укажите свои данные:

```python
AI_API_KEY = "ваш-ключ-ChatCI"
AI_BASE_URL = "https://chatci.online/proxy/v1"
AI_MODEL = "deepseek-v4.1-flash"
```

`config.py` содержит секретный ключ. Не публикуйте его в GitHub и не отправляйте в общий чат.

Если ключ не указан, программа запускается в режиме шаблонной генерации.

## Запуск

Основная новая версия:

```powershell
python app_qt.py
```

Старая Tkinter-версия:

```powershell
python app.py
```

Для интерфейса с PySide6 используйте именно `app_qt.py`.

## Как пользоваться

1. Запустите `app_qt.py`.
2. Введите название продукта.
3. Добавьте описание и преимущества.
4. Укажите цену или оффер.
5. Выберите площадку, аудиторию и тональность.
6. Нажмите **«Сгенерировать 3 варианта»**.
7. При необходимости отредактируйте текст.
8. Используйте кнопки **«Копировать»**, **«Проверить»** или **«Перегенерировать»**.

## Режим без ИИ

Если ключ пустой или ChatCI недоступен, программа автоматически использует встроенные шаблоны.
