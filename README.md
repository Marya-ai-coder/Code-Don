# Модуль ввода (форма / чат-бот)

Веб-приложение на **Streamlit** для интерактивного ввода запросов и генерации контента нейросетью с поддержкой встраивания в веб-сайты (например, Tilda).

## 🚀 Реализованный функционал (роль «Разработчик модуля ввода»)

1. **Конфигурация страницы и каркас**:
   - Настройка страницы (`st.set_page_config`) с заголовком и иконкой.
   - Заголовок (`st.title`) и пояснения (`st.caption`).
   - Изолированная форма ввода через контейнер `st.form("input_form")`.

2. **Поля ввода и управление генерацией**:
   - Поле `st.text_area` для многострочного ввода пользовательского запроса с плейсхолдером и подсказкой.
   - Поле `st.selectbox` для выбора роли/стиля ответа (Креативный, Деловой, Технический, Краткий пересказ).
   - Кнопка отправки формы `st.form_submit_button("🚀 Сгенерировать")`.

3. **Отображение результата и копирование**:
   - Вывод сгенерированного текста в блоке `st.code(..., language=None)` со встроенной кнопкой быстрого копирования в буфер обмена в один клик.

4. **Кнопка «Перегенерировать»**:
   - Кнопка `st.button("🔄 Перегенерировать")` размещена строго вне формы.
   - Реализована блокировка `disabled=not has_result` (неактивна, если нет сгенерированного ответа).
   - При нажатии повторно вызывает логику генерации для сохраненного запроса и обновляет интерфейс через `st.rerun()`.

5. **Надежность и состояние**:
   - Валидация входных данных на пустоту (`.strip()`) с выводом предупреждения через `st.error`.
   - Перехват исключений через `try / except` с выводом ошибки в UI.
   - Сохранение состояния между перезапусками страницы через `st.session_state`.
   - Встроенный автономный демо-режим (работает без ключей API) и готовая поддержка YandexGPT / OpenAI через `.streamlit/secrets.toml`.

---

## 💻 Локальный запуск

1. Установите зависимости:
   ```bash
   pip install -r requirements.txt
   ```

2. Запустите Streamlit-приложение:
   ```bash
   streamlit run app.py
   ```

3. Откройте в браузере: `http://localhost:8501`.
